# Brand assets

The official Fitsol logo SVGs live here and are wired into
`src/app/_components/Wordmark.tsx`.

| File | Use | Status |
|---|---|---|
| `fitsol-logo-full-colour.svg` | Full-colour logo (green mark + navy wordmark) — white surfaces, e.g. the public passport. | **present, wired** |
| `fitsol-logo-white.svg` | White logo — the dark-teal header bar. | **present, wired** |
| `fitsol-logomark.svg` | Logomark only (no wordmark) — compact / favicon / mobile. | not yet supplied |

Keep the SVGs optimised and do not recolour them. Replacing a file here updates
the logo everywhere it is used (no code change needed) as long as the filename is
unchanged.
